# Python 3.11 ONLY. The system default python here is 3.14, which has no
# torch/diffusers wheels. Create the venv with:  py -3.11 -m venv .venv
#
# torch is deliberately NOT listed here. On Windows a plain `pip install torch`
# can silently resolve to a CPU-only build that then computes on the processor
# without ever saying so. Install it first, from the CUDA index:
#
#   .venv/Scripts/python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu124
#
# then:  .venv/Scripts/python.exe -m pip install -r requirements.txt
#
# Installed and verified here: torch==2.6.0+cu124 (CUDA 12.4, driver reports 13.1).
#
# xformers is intentionally absent: on Windows it is a version quest for
# roughly zero gain over torch 2.x built-in SDPA.
#
# ---------------------------------------------------------------------------
# WHY THESE ARE PINNED
# ---------------------------------------------------------------------------
# These are the exact versions card-forge was built and verified against.
# They are pinned rather than left as floors because diffusers 0.39.0 declares
# only `transformers>=4.41.2` with NO UPPER BOUND, so an unpinned install is
# free to pull a future transformers major release into the one place it hurts
# most - pipeline construction. Re-resolving on a new machine and getting a
# different pairing is exactly the failure this file exists to prevent.
#
# The diffusers 0.39.0 / transformers 5.14.1 pairing is newer than most SD 1.5
# guidance online, so it was checked directly rather than assumed:
#   - diffusers imports CLIPTextModel / CLIPTokenizer / CLIPImageProcessor /
#     CLIPVisionModelWithProjection from transformers 5.14.1 without error
#   - StableDiffusionPipeline and DPMSolverMultistepScheduler both resolve, and
#     the scheduler instantiates from a config
#   - CLIPTextModel.from_pretrained loads a REAL SD 1.5 text_encoder checkpoint:
#     all 196 weight keys load, token-embedding std 0.01395 (the trained value,
#     not random init), and a forward pass returns a finite (1, 77, 768) tensor
#   - AutoencoderKL loads with variant="fp16" and enable_slicing() works
#
# NOT verified (needs the ~2GB UNet download and the GPU): full
# StableDiffusionPipeline.from_pretrained assembly, .to("cuda"), and the actual
# denoise loop. See README "If the smoke batch fails" before changing anything.
# ---------------------------------------------------------------------------
